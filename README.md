# CGA Competition Scoreboard

A simple scoring web app for the Cambridge Grads Academy competition.

- Two categories: O Levels and FT
- 6 teams, 5 rounds, scored with dropdowns
- Live leaderboard with ties handled
- Scores and names are saved in the browser (localStorage)

## Run
Open `index.html` in any browser. No install needed.

## Notes
- The "Export results as PDF" button relies on the Claude artifact download feature and only works on the Claude-hosted page.
